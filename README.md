# Demo FoundryIQ + agentes para procesos inteligentes

Demo estática y simulada para Microsoft IQ Summit.

## Objetivo

Mostrar a clientes de negocio cómo Microsoft Foundry, FoundryIQ, agentes, servicios de IA, gobierno y GitHub Copilot encastran como piezas de un ecosistema para pasar de productividad individual a procesos inteligentes.

## Publicación

Este repositorio usa GitHub Actions para publicar en GitHub Pages.
